ESP32 Climate Monitoring System

A complete environmental monitoring system featuring an ESP32 firmware stack and a fully‑integrated host‑side analysis pipeline.

Project Overview

This project is a long‑term environmental monitoring system built around an ESP32, designed to collect climate‑relevant sensor data and transform it into a complete analysis package using a modular host‑side toolchain.

Climate Relevance & Engineering Tradeoffs

  • Sensors: BME680 + CCS811 for broad environmental profile
  • ESP32: low‑power, Wi‑Fi, mature ecosystem
  • CSV: human‑readable, easy to debug
  • Long‑term monitoring: climate trends + anomaly detection

Lessons Learned

  • Modular host‑side design is extremely effective
  • Binary conversion improves performance
  • Trend detection requires careful timestamp normalization
  • Anomaly detection must handle sensor noise
  • SD reliability is critical
  • Firmware complexity depends heavily on sensor APIs
